# CDFW/MARE ROV data needed to validate Central Coast spot rankings

Prepared September 26, 2026; **not sent**. Scope: open reference sites from Monterey to Point Conception, especially observations in 200–300 ft. Protected-site records, if provided, are for model comparison only and must never become target coordinates.

The [CDFW ROV program](https://wildlife.ca.gov/Conservation/Marine/MPAs/Management/monitoring/ROV) describes deep-water transects and habitat observations. The [2025 CDFW data user manual, Appendix II](https://www.pcouncil.org/documents/2025/02/h-4-a-supplemental-cdfw-report-1-california-department-of-fish-and-wildlife-report-on-accepted-practices-guidelines-for-groundfish-stock-assessments-meeting.pdf/) names four linked tables: `10mSubunitID_Summary`, `Fish1sec`, `TransectID_Summary`, and length data. CDFW states that a data sharing agreement may be provided to parties requesting the data. SkipperCast has not obtained such an agreement or the original database.

Request the original records for all available survey years, including 2014–2016 and 2019–2021, together with a data dictionary, stable table/version IDs, redistribution terms and permitted public aggregation scale. For each transect, retain site, line, dive, date, designation (MPA/reference/other), depth, start/end geometry, usable swept area, visibility, effort and zero-observation lines. For each 10 m subunit, retain original ID, WGS84 and native coordinates, source/processing frame, year, position method, depth, temperature, hard/mixed/soft habitat and separate rock/boulder/cobble/sand/mud distances or areas. For each fish observation, retain second-level timestamp, taxon identification confidence, count, matched subunit/line, location, habitat, usable-data flag, observation-range limit, and stereo size only where independently matchable.

The manual estimates **3–6 m** spatial error for cleaned ROV observation points. It also documents gaps from stops, pulls and high-relief backsides, one-second fish timing, and the fact that several fish can produce non-integer allocated counts in aggregated records. Do not reduce that spatial error to the five-decimal coordinate display, count adjacent subunits as independent surveys, equate visual density with hook-and-line catch rate, or impute fish absence from unusable footage. Semi-pelagic rockfish can have different detection probabilities from demersal fish.

Acceptance test for an import: verify file hashes and schema; preserve unsuccessful transects and unusable flags; join tables by stable IDs and time; reproduce published open-reference aggregates within documented tolerance; buffer each observation by its supported horizontal error before joining a seabed class; exclude protected locations from public candidate geometry; and hold out later years and different coastline sections when testing whether habitat features improve rankings. If access or rights are withheld, keep the current public 10 m analysis as regional context only.
