# Monterey Peninsula to Point Sur: limited preview

This package fills the `monterey-sur` browsing band's local map, forecast, tide, rules and protected-area contracts. It is a **preview**, not a coastwide fishing map or a route recommendation. The map deliberately contains zero qualified fishing marks, areas, drifts or chartplotter exports.

## Reviewed sources and interpretation

- [CDFW's official MPA polygon service](https://services2.arcgis.com/Uq9r85Potqm3MfRV/arcgis/rest/services/biosds582_fpu/FeatureServer/0) returned nine features intersecting the exact regional envelope. The bounded snapshot is [protected-areas.geojson](../dist/regions/monterey-point-sur/protected-areas.geojson). Some northern polygons touch the Monterey Bay package too; overlapping packages must keep the same exclusion. Every displayed MPA is excluded conservatively from automated fishing positions, even where a species-specific exception exists.
- Six official CDFW area pages cover [Carmel Pinnacles](https://wildlife.ca.gov/Conservation/Marine/MPAs/Carmel-Pinnacles), [Carmel Bay](https://wildlife.ca.gov/Conservation/Marine/MPAs/Carmel-Bay), [Point Lobos](https://wildlife.ca.gov/Conservation/Marine/MPAs/Point-Lobos), [Point Sur](https://wildlife.ca.gov/Conservation/Marine/MPAs/Point-Sur), [Edward F. Ricketts and Lovers Point](https://wildlife.ca.gov/Conservation/Marine/MPAs/Edward-F-Ricketts-Lovers-Point-Julia-Platt), and [Asilomar](https://wildlife.ca.gov/Conservation/Marine/MPAs/Pacific-Grove-Marine-Gardens-Asilomar). The September 25 legal packet recorded their normalized hashes alongside the unchanged Central species sources. A separate Vandenberg source remains unavailable, but it is outside this regional legal scope.
- [NWS PZZ565 and PZZ576](https://www.weather.gov/marine/mtrmz) cover nearshore and offshore waters south of Point Pinos. [NOAA Monterey station 9413450](https://tidesandcurrents.noaa.gov/noaatidepredictions.html?id=9413450) supplies tide reference. [NDBC 46236](https://www.ndbc.noaa.gov/station_page.php?station=46236) and [46042](https://www.ndbc.noaa.gov/station_page.php?station=46042) are both **north of the regional bounds**; neither measures Point Sur conditions or the harbor entrance. The [City harbor page](https://monterey.gov/your_city_hall/departments/public_works/harbor_and_marina/) supplies contact and facility context, not live entrance clearance.
- The [original USGS Offshore Monterey grids](../catalog/candidates/usgs-offshore-monterey-original-grids.json) overlap only the north of this sector. NOAA's bounded native-depth review found no cells in the selected original NOAA set passing the app's strict measured 25–200 ft and ≤1 m uncertainty screen here. Neither result establishes an absence of fish. A native chart-datum depth, local uncertainty, substrate, hazards and approach review is required before any fishing point is published.

## Repeatable update and rollback

The package reuses `regions/<id>/region.json`, the jurisdiction watch registry, deterministic builders, the daily/half-hourly feed jobs, and the draft rehearsal matrix. `scripts/refresh_reviewed_closures.py` checks the protected-area snapshot against CDFW; legal text changes remain held until a new explicit hash-bound decision. Run the draft rehearsal before promotion and examine each raw source status and populated cell coverage. A successful page fetch is not safe access. If a source or map is wrong, revert the coherent Git/Sites version or withdraw this preview package; do not fill missing fishing positions from a neighboring region.
