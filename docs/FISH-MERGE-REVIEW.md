## Concrete extension points and constraints

- **Routing:** SkipperCast `server/app.ts` registers anonymous APIs before `requireUser` and catches `/api/*` afterward. Add report/history/ocean and bounded physical proxies in an explicit public router before the private gate. Avoid `/api/health` collision: SkipperCast uses it for liveness/build; Fish uses it for report readiness. Preserve both meanings under distinct named endpoints.
- **Shell/build:** use SkipperCast Vite sources and build-generated hashed pages/assets. Fish esbuild's stable `/assets/styles.css` and shadow-root inline `<style>` are incompatible with SkipperCast's `style-src-elem 'self'`. Port styling into built assets; test actual CSP. Fish's full report creates another MapLibre map, so simply embedding `/report` leaves a duplicate map/forecast/controller.
- **State:** `web/state.ts`, `web/profile.ts`, `web/ports.ts` provide URL/profile/port semantics. Fish currently uses `place/mode/species/area/hour`; SkipperCast uses `region/coast/profile/target/area/hour`. Add deterministic aliases and translation. SkipperCast's `morro-bay` port differs from Fish `morro`, Avila maps to the Morro/Avila package, and terrain-only corridor sites need explicit report-unavailable state. Update Back/Forward and shared links, not just selectors.
- **Coverage:** Fish `forecastAreaForPlace` binds only Morro, Cambria and Avila. Monterey/Big Sur/Arguello/Conception terrain does not have Fish-local forecasts. Habitat publisher region identity restricts place naming; proximity never creates a forecast or legal binding.
- **Storage:** Fish's report/history/ocean reads depend on its dedicated D1 `reports`, `pipeline_runs`, `auxiliary_snapshots`. SkipperCast `DB` already owns private tables, including subscription concepts. Introduce dedicated bindings or reviewed namespaced migrations; do not point Fish SQL at the existing account database casually. Never export private subscriptions, trips, fleet or advisor rows into git/public assets.
- **Scientific publication:** Fish habitat government release uses a dedicated private R2 bucket and exact SHA/ETag/range/current-screen gates. Site deployment does not transfer those objects. Use a bounded release proxy or explicit approved binding, preserve private-prefix denial including encoded paths, and keep full-context exact-source binding versus independently valid curated fallback.
- **Clocks:** retain issued/acquired/observed/sample/valid/fetched/generated times independently. A newly assembled report cannot refresh retained observations, annual history, catches, masks or habitat screen expiry. Keep absent sources absent.
- **Rights:** preserve Fish `NOTICE.md`, font/library notices, NOAA/USGS/NAIP contributor receipts and CDFW CC BY attribution. Fish code has no declared blanket application license; repository owner authorization covers this task, while source-specific restrictions still apply. SkipperCast production currently declares `source_use: noncommercial`; Fish government-only commercially eligible habitat must not be replaced silently by mixed or excluded commercial-restricted material. No monetization changes are authorized by the merge.
- **Scheduled data:** Fish Cron refreshes report, ocean and recent history; SkipperCast cron already owns watchdog behavior and public jobs run through GitHub. Compose tasks deliberately or preserve existing upstream snapshot delivery. Never claim ongoing collection from bindings or configuration alone; source clocks and distinct persisted run receipts must be witnessed.
