# C2 terrain-RGB: no unsupported cell encodes as an elevation (2026-10-22)

- Branch: `claude/c2-unsupported-encoding`, from `origin/claude/update-pr835` (head `86b87b6cc661`).
- Code commit: `1698ef594edc` (this report is committed on top of it).
- Synthetic data only. Existing PR branches untouched. Not merged.

## Choice

Option 1 from `2026-10-22-viewer-mask.md` (on `claude/viewer-mask-aware`): keep alpha=0 and fill
RGB under it with the nearest supported cell. A reader that ignores alpha now sees a flat, plausible
edge instead of -10000 m. A reserved sentinel (option 2) would still be a wrong height if missed.

## Change

- `coast_contours.py`: new `encode_terrain` (fill, range check) and `decode_terrain` (masked array).
- A tile with no supported cell is not written (it cannot be filled); counted in the manifest.
- `manifest.json` keeps `schema_version` 1 and adds `terrain_encoding_version: 2`, `terrain_decode`
  (formula, `support: alpha`, `unsupported_alpha: 0`, `unsupported_rgb: nearest_supported_fill`,
  `unsupported_rgb_is_data: false`) and `terrain_tiles_without_support`.
- `CONTOURS.md` documents the decode contract.

## Compatibility

- Supported cells (alpha=255): RGB identical to version 1.
- Alpha: identical. Alpha-aware readers (such as the mask-aware viewer) need no change.
- Only RGB under alpha=0 changes (was 0, now fill). Old tiles stay valid; readers tell them apart
  by `terrain_encoding_version` (absent = 1).
- Manifest changes are additive. `terrain_tiles` now counts tiles written; before, it counted
  tiles attempted. They differ only when a tile has no support.
- The fill is not data. Keep masking on alpha.
- Not checked: the viewer on this base (it lives on `claude/viewer-mask-aware`, a different line).

## Tests (`research/tests/test_coast_mvp_contours.py`, marked `gis`)

- Hole raster through the full build: decode gives the mask; raw RGB never decodes below -1000 m
  and stays within the supported range.
- Unit: fill is the nearest supported value; alpha is exactly 0/255; no RGB=0 cell; an empty tile
  and an out-of-range elevation raise.
