## R3. What to remove and what to keep

- **Remove both exact replay pairs from the CI allowance** (`scripts/pytest_report.py:56–61`). This is an unreachable-in-CI finding, not “no raiser found.” The line-47 collection skip already covers both tests. An authorized local run that opts in without the original ledger or pre-scan receipt still skips in pytest, but would no longer get the reporter's `Historical replays not run` treatment; local `--strict-skips` would reject that row (`scripts/pytest_report.py:101–103,122–124,130–132,262–270`). The documented local archive command runs pytest, not the strict reporter (`docs/engineering/testing.md:10`). Keep that pytest behavior unchanged and call out the strict-report difference in the follow-up.
- **Keep lines 26–31, 38–44, 47, 50 and 51.** Each covers a reachable missing-input or opt-in skip today (R1–R2). In particular, the host-archive reason is the one CI actually uses for the six marked tests; do not remove it with the pairs.
- **Keep line 34.** It covers the image tests on the workflow's dependency set. **Keep line 37 for now.** Normally unused is not impossible: both tools must resolve, and there is no workflow guarantee (R2). Do not bundle runner provisioning or advisor dependency changes with this removal.
