## R3. Map URLs: shareable, not marked for indexing

- The canonical middleware implements an HTTP `301` for host/scheme cleanup (including `www` and a trailing host dot); it keeps the path and query and removes the fragment from the redirect target. On canonical HTTPS `https://skippercast.com`, it does not redirect `/map`, strip `?region=`, or assign a canonical HTML link (`server/middleware/canonical.ts:10–26`; `server/app.ts:44–46`).
- `/map` serves `app.html` with or without the query. `/?region=…` also selects that shell rather than home. It has `noindex` and no canonical link. A bare map without a resolved region or coast can have a **browser-side** `location.replace` to a saved home or the landing; that is not an HTTP `301` for the address. The Share action constructs `/map` with region or coast and carries supported state; the share function’s use of “canonical link” does not create a `<link rel="canonical">` (`server/routes/assets.ts:16,34–42,107–115`; `dist/app.html:2–18`; `tests/test_site_discovery.mjs:46–54,62–71`; `web/app/main.tsx:48`; `web/ports.ts:207–220`; `web/share-link.ts:57–94`).
- With `HTMLRewriter`, the app response can replace only `og:title` and `og:description` using a known region and optionally one matching reviewed port. Repeated `/map` `region` parameters keep the default shell/preview; unknown regions have no override. The generic `og:image` and `noindex` remain. That is a preview path, not an indexing path. `/map` and the deep-link variants were not fetched live (`server/routes/assets.ts:115–133`; `server/og.ts:4–14`; `dist/app.html:7,12–18`).

## R4. Ranked gaps and one small follow-up

1. **Metadata coverage for the listed pages.** Only home sends an explicit Open Graph image; `/report`, `/about` and `/methodology` send textual cards, and eight other pages send neither measured OG tag. `/skill` and `/species-research.html` lack a description. These are source/live agreements, not broken routes or evidence of lower ranking (R1).
2. **No Spanish discovery links on the 12 pages.** Static heads and sitemap advertise no alternate; gated advisor pages are a separate implementation. Whether a static page should have an independently discoverable Spanish edition, and which ones, is for the owner (R1–R2).
3. **Coverage and indexing can differ.** No region HTML family is listed, a linked evidence page has no stated exclusion, and the generated sitemap can include an active port whose page temporarily says `noindex`. None of these facts calls for indexing the map, enabling advisor pages, or silently changing the owner’s public-page choices (R2–R3).

**One proposed unit, tests only (estimate: 60–90 minutes).** Extend `tests/test_site_discovery.mjs` to check the saved source’s listed-page metadata through its existing static reads and offline rendered-page fixture: require a nonempty title, exactly one self-canonical and no `noindex` for each listed URL, and a nonempty text/image tag wherever R1 already shows one. Do not require the currently absent tags, freeze copy, change the snapshot, or modify any page, sitemap, robot directive or header. The test would catch, for example, a missing canonical or lost report preview title that the current iteration does not check across the whole list. Acceptance after separate admission: `node --test tests/test_site_discovery.mjs` offline; removing an existing tag in a disposable copy must trigger the matching assertion. Today the static test pins sitemap/robots and selected canonicals/robots plus home preview; its server snapshot records robots/canonical/header, not rendered titles or previews (`tests/test_site_discovery.mjs:18–59,62–98,100–138`). The advisor test covers the switch, sitemap entries, Spanish alternate and robots output in fixtures (`tests/test_advisor_pages.mjs:356–375`); it is not a check of live static pages.
