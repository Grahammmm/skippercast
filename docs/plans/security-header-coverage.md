## R1. HTTP response paths

`fetch` is `app.fetch` (`server/index.ts:67`). In order: metrics → request ID → security headers → context → cost ceiling → canonical redirect → routers (`server/app.ts:44–76`). The first two middleware functions call `next()` without a normal early return; metrics only observes the result and request ID preserves the headers even when it rebuilds a JSON error (`server/analytics.ts:100–121`, `server/middleware/request-id.ts:11–31`). The security middleware applies `secure()` **after** downstream returns, including when a downstream handler never calls `next()`. `secure()` sets (rather than appends) the same seven values and copies an immutable response when necessary; the renewal cookie remains a separate operation (`server/middleware/security-headers.ts:8–17`, `server/security-headers.ts:43–60`).

Both permit `'self'`, and `img-src` also permits `data:` and `blob:` (`server/security-headers.ts:10–20,22–40`). ## R4. Ranked gaps and one possible follow-up

1. **Low (estimate): unused external permissions.** The OpenStreetMap entry in both directives and the NOAA ENC image entry are not backed by current direct loads in this audit. ENC **connect** is in use; do not remove it on this evidence. This is an unnecessary allowance, not an observed blocked feature or bypass (R3).
2. **Low / unverified on the wire (estimate): exception boundary.** Ordinary 4xx/5xx responses are covered. The outer API error fallback is not guaranteed the full set, and an escaped error's platform response is outside the app's contract. Do not change error semantics or promise platform coverage based on this audit (R1, `server/middleware/error.ts:12–22`).
3. **Low (estimate): coverage guard blind spots.** The existing literal scan cannot catch a new TS-only fetch or distinguish an image host from a connection host; the HTTP test samples selected paths rather than the whole matrix (`tests/test_security_headers.mjs:64–115`). No missing live client origin was identified (R3).

**One proposed unit, 60–90 minutes (estimate), for separate admission:** after the owner confirms no supported Leaflet street view needs the host, remove only the unused OpenStreetMap permissions in `server/security-headers.ts`; adjust `tests/test_security_headers.mjs` to classify the legacy literal as an unused initializer, not as an allowed fetch or a navigation link. Have the offline test guard the no-production-caller premise and assert OSM is absent from both emitted directives, with active NOAA ENC still in `connect-src`. Run `node --test tests/test_security_headers.mjs` plus `python scripts/check_repository.py`. No change to routing, static publication, provider rights or the separate ENC image permission in that unit. This report does not authorize or implement the removal.
