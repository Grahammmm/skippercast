## R3. Per-request cost (source estimates, not measurements)

`wrangler.jsonc:50–54` enables Workers Logs at `head_sampling_rate: 1`. Per `docs/cloudflare.md:134–138`, every invocation is eligible to be logged, including its outcome even if it emits no explicit lines. Estimates below count **application console calls**, not Cloudflare's total log events, bytes, retention or actual bill. Analytics Engine has separate sampling for successful feed requests (`server/analytics.ts:100–119`).

| Path | Estimated explicit lines | Why |
| --- | --- | --- |
| Every HTTP request; ordinary successful asset/cache-hit control | **0 unconditional**; **0** on a clean hit. | Common middleware is not an access logger (`server/app.ts:44–59`, `server/analytics.ts:100–119`); cached return bypasses write (`server/edge-cache.ts:58–64`). |
| Normal HTTP miss, optional write failures and thrown API errors | **0** if read and side writes succeed; **1** per failed meter/last-known/public-feed cache write at its catch; edge store can log **1–2** per failed store path. **1** for a mapped API exception, in addition to any producer log before it. | `server/cost-ceiling.ts:79–94,185–196`, `server/edge-cache.ts:42–50`, `server/feeds.ts:427–443`, `server/middleware/error.ts:12–22`. Returned error responses do not by themselves invoke the mapper. |
| Boat lookup | **0** cache hit/early return; **1** on global-cap return; **1** on paid success, **2** on caught paid failure, not counting independent middleware. Invalid input that throws takes the API mapper path. | `server/routes/boat.ts:20–40`. |
| Scheduler-authenticated HTTP jobs and Advisor paths | **0** verifier lines on success, or typically **0–1** for a refused token/failure; downstream trip delivery may add **1 per unconfigured delivery call**. Advisor **1 per wrapper event**, including some normal operations; no fixed per-request total. | `server/job-auth.ts:47–77`, `server/routes/jobs.ts`, `server/trips.ts:115–120,249–263`, `server/advisor/log.ts:31–35`; R2 wrapper callers. |
| Cron (not HTTP) | **0** for healthy prune/watchdog and no trip queue or Advisor event. With queue enabled, **1** per returned schedule summary (even unchanged), plus conditional failure/health/Advisor events. **96 scheduled opportunities per 24 hours** at the configured 15-minute interval, not measured arrivals. | `wrangler.jsonc:50`; `server/index.ts:26–43`, `server/trips.ts:156–158`, `server/watchdog.ts:138–156`. |
| Queue (not HTTP) | **1** summary per completed trip batch plus **1 per caught retry** and any underlying delivery/feed lines. **1** trip DLQ summary per batch. Advisor queue has its own wrapper events. | `server/index.ts:46–64`, `server/trip-queue.ts:95–124`, `server/advisor/consumer.ts:902–921,957–960`. |
| Browser | **0 Workers console lines** added by these calls. On a clean load, client failure handlers stay quiet; on a bad map load, renderer/tile failures can repeat without one-per-request semantics. | R1 browser trigger column and `web/map/engine.ts:218–227`, `packages/coast/src/coast3d/viewer.ts:193–205`, `web/telemetry.ts:190–211`. |

No traffic mix or failure rate was measured, so there is no site-wide average or dollar estimate. Automatic request/invocation metadata, platform-generated errors and analytics are not counted as these explicit call sites.
