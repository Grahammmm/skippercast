## R3. Clock, locale, zone and network

- **Locale can fail a test.** `tests/coast/coast-habitat-event.test.ts:35,46,84,103` matches ASCII counts in a status that uses default-locale `toLocaleString()` (`packages/coast/src/coast3d/viewer.ts:259`). Reproduce with `LC_ALL=ar_EG.UTF-8 TZ=UTC node --test tests/coast/coast-habitat-event.test.ts`. The first error for each is “The input did not match the regular expression”: the cases starting at :30, :42, :76 and :101 expect `3`, `15`, `0` and `1` respectively but see Arabic-Indic digits. These are diagnostic locale failures, not the R1 defaults.
- **Locale and process zone change the expected text without necessarily failing.** `tests/coast/shore-review.test.ts:40–42` builds its expected dated evidence with the same default-zone/default-locale `toLocaleDateString()` as production (`packages/coast/src/shore-review.ts:44–46`). A bare `2026-09-01` is UTC midnight, which is August 31 in Los Angeles. This test cannot independently pin the intended calendar day. Its null branch (:36–39) and the admission tests' explicit `NOW` (:4) do not depend on those defaults. `tests/coast/coast-report.test.ts:63–67` compares two rendered history strings in the same process, not a fixed number format (`packages/coast/src/ui/history.ts:24,45`); the fixture dates use the county zone (`tests/coast/coast-report.test.ts:16`), not the process zone. The palette SVG case specifies `America/Los_Angeles` (`tests/coast/coast-palette.test.ts:58–62`).
- **Real wall clock.** `tests/coast/coast-report.test.ts:14–16` builds rolling fixtures from `new Date()`. Time-bearing assertions at :33–43, :50–52, :63–71, :74–85 and :91–98 use those derived inputs. The pure report state calls pass `now`; the mounted report can also read live time (`packages/coast/src/state/report-context.ts:10–16`; `packages/coast/src/coast3d/report.ts:96`). The fixture and renderer can straddle turnover. `tests/coast/coast-embedded.test.ts:50–55,100–109,117–138,155–158` uses dated 2027 reef receipts and can cross the fixture expiry against `viewer.ts:278,330–331`; :149–152 uses a 60-second live deadline, :189–193 seeds current admission from real time then drives expiry, and :199–209 assumes the real date falls between the synthetic 2000/2999 shore dates. The controlled cases at :139–142 and :161–166 replace `Date.now`. Habitat-event reef cases at `tests/coast/coast-habitat-event.test.ts:30,42,57,76,87,101` use the future deadline at :19 against the default `Date.now()` in `packages/coast/src/coast3d/regional.ts:41`, called by `viewer.ts:255`. By contrast, `tests/coast/habitat-lifecycle.test.ts:6,31–44,56–65,98–end` uses fixture or injected time. `tests/coast/coast-overlays.test.ts:96–108` is sensitive to machine load: “a pathological comb stays under the hard caps by coarsening the drape” measures with `performance.now()` at :100 and requires less than 5,000 ms at :106, in addition to checking the geometry caps.
- **Network.** No live endpoint is required. Fetch-bearing cases use injected or replaced fetch (`tests/coast/bottom-loader.test.ts:68–86,116–119`; `tests/coast/coast-report.test.ts:51,55,59,70,88,92–97`; `tests/coast/coast-embedded.test.ts:83,97,124,145,151,170,174,184,192`; `tests/coast/coast-habitat-event.test.ts:59`; `tests/coast/habitat-lifecycle.test.ts:22–29`). The surface-field and shading reference inputs are local files (`tests/coast/surface-field.test.ts:28–32`; `tests/coast/coast-shading.test.ts:72–74`).

As a check, `node --test --test-concurrency=2 tests/coast/*.test.ts` in a network namespace without external interfaces gave 168/0/0 for `TZ`/`LC_ALL` pairs `UTC`/`C`, `America/Los_Angeles`/`en_US.UTF-8`, `Pacific/Kiritimati`/`de_DE.UTF-8` and 164/4/0 for `UTC`/`ar_EG.UTF-8` (the four cases above). This is not a future-clock test.
