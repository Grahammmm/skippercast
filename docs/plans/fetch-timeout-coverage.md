## R1. Inventory

**Deadline** means an application time limit, not a generation check, retry delay or browser-internal limit. **Cancel only** means the request can still wait indefinitely while its owner remains active. **None** means neither at that route. Paths beginning `/` are same-origin unless a host is named. **Yes** means eligible for `shareStatic`; **bypass** means it enters that wrapper but receives no shared deadline. The wrapper times the transfer through successful body buffering, races each caller's signal separately, and cancels a pending `region.json` transfer when the last reader leaves (`web/shared-fetch.ts:75–107,118–141`). `watchDegraded` and telemetry observe responses but only forward request options (`web/degraded.ts:95–109`, `web/telemetry.ts:214–222`); `web/offline-response.ts:7–21` only interprets provenance after a response arrives.

## R3. Third-party paths most likely to produce a visible hang (estimate)

Ranked by the prominence of the affected UI and how many awaited requests can hold it, **not** by measured host reliability. “Unbounded” here is no fixed request deadline, even where cancellation exists.

| Rank | Host and path | Why this rank |
|---|---|---|
| 1 | `imagery.nationalmap.gov` Aerial, then `gis.charttools.noaa.gov` ENC when selected | Tiles are the visible map background. `CONNECT_ORIGINS` is permission, not a traffic list (`server/security-headers.ts:9–20`). Ordinary live CO-OPS reads and the live ArcGIS MPA request already have deadlines (R1).
