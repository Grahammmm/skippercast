## R1. From source to screen

**How to read the tables.** “Feed” means a same-origin `/feeds/` GET: ordinary 404 for absent keys or objects, 503 for a missing object in a resolved release or no bucket; a changed object during an `If-Range` reread can also return 503, which is not the ordinary JSON-fetch path. A thrown read outside `/api/` is not mapped by the API error handler. “API” below means unknown region 404 and dependency/validation exceptions mapped to a generic 503 (daily also has a 400 for unknown part and a rate limit). Neither an ordinary HTTP error nor a rejected request starts the banner (`server/feeds.ts:312–322,352–378,400–415`, `server/middleware/error.ts:12–22`, `server/routes/public.ts:84–113`, `web/degraded.ts:70–102`).

**Ceiling** means a different branch: only when the bound bucket is over budget. Eligible GETs are `/feeds/` except the seafloor prefix, the four public feed APIs, and `/api/om/` paths. On a hit, the Worker returns the saved 200/206 with `X-SC-Degraded: cost-ceiling`, normally `X-SC-Last-Known-At`, and `no-store`. Eligibility does not guarantee a copy: query and Range must match; the original must have a body within the size bound, no `private`/`no-store` or `Set-Cookie`, and not be an edge hit. With no saved copy the underlying route runs without the bucket: an eligible error becomes the marked 503 without a save time; other downstream responses are marked as-is, even if they are not saved copies. The wrapper watches resolved page fetches, before consumers check `ok`, not every subresource or another worker's fetch. An earlier banner can remain during an unmarked error (`server/cost-ceiling.ts:111–130,169–225,234–251`, `web/degraded.ts:36–50,70–110`, `web/app/main.tsx:23–30`, `web/landing/main.tsx:70–75`). The named offline test source checks private/no-store, cookie and unsuccessful response exclusions plus a positive replay, not view rendering (`tests/test_rf2021_3_last_known_cache_control.mjs:7–55`).

**Landing tides are a separate read.** The strip requests NOAA's observed water level, not the app's chosen-station predictions. NOAA 404/503, a rejection, a ten-second timeout, or an answer with no usable rows renders `landing.reading.none` and the unavailable/stale provenance on the tide tile; no Worker's last-known response for this URL (`web/landing/readings.ts:89–95,153–171,183–197`, `web/landing/Readout.tsx:20–37`).

Browser offline behavior for these data routes is network-first: a **returned** HTTP 404 or 503 is not the trigger to use the pack; a **rejected** request is. A pack response gets `X-SC-Offline`; the separate coastal snapshot path applies its own admission. The `/map` document has a separate stalled-network fallback after 1.5 seconds if a committed pack holds the page. Without an eligible copy, that navigation still waits. The masthead freshness indicator separately reflects tile ages and `navigator.onLine` (`shell.fresh.stale`, `shell.fresh.offline`, `shell.fresh.unknown` via its label; an offline span is visible); manual refresh can add `shell.refresh.failed` or offline feedback. ## R3. Language, state, and clock

- **Both languages, yes.** `shared.degraded.saved` and `shared.degraded.savedAt` have English and Spanish copy (English starts “Live data is paused for today…”; Spanish “Los datos en vivo están pausados por hoy…”). Both layouts and landing feed the same component the current `language.value`. Landing's startup table is English-only by design; the deferred Spanish table supplies its translations, and a load failure falls back to English. `Degraded` is not a word/badge printed in either language: it is `null` or `{since}`; the localized notice is its visible representation. The element is `p.app-degraded[role=status][data-degraded=cost-ceiling]` (`catalog/app/strings.json:2766–2767`, `web/strings.es.generated.json:2750–2751`, `web/degraded.ts:19–28,112–121`, `web/degraded-notice.tsx:8–11`, `web/landing/i18n.ts:1–10`, `web/landing/main.tsx:70–83`, `web/app/Masthead.tsx:120`, `web/app/Mobile.tsx:130`, `web/landing/Landing.tsx:158`).
- **Pacific day, no.** `degradedText` uses the selected language's locale, but `localTime` requests weekday/hour/minute with **no `timeZone`**. The weekday/time are browser-local, Pacific only if the browser is set there. The budget day and recovery checks use UTC, not the display zone. A timestamp before 2020, missing, invalid, or more than five minutes ahead cannot date the banner; within a marked UTC day the oldest usable time wins. The notice does not expire at midnight alone: a verified later-day live read clears it (same-origin basic response, current Date and positive live provenance, not a saved or old cache hit) (`web/degraded.ts:21–24,30–50,62–89,112–121`, `web/i18n-core.ts:62`).
