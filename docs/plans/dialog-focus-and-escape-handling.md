This is a source audit, not a browser run. **Native** means `showModal()` makes the page behind the dialog inert; it does not promise an uninterrupted loop through dialog controls (the spec allows the browser-chrome stop, `e2e/overlay-keyboard.spec.ts:94–104`). **Yes** means a scripted Tab wrap; **No** means no local trap, even if a parent modal still confines Tab. For local key handlers, Escape must reach the named surface's handler. The inventory covers user-facing overlay components and their distinct entry paths, not every always-visible content card, ordinary form widget, or browser/OS prompt.

## R2. Which patterns could be shared

`rememberOpener` captures current focus except body, `restoreFocus` tries the connected opener then the `.app-account-trigger` fallback (and does nothing for a null opener), and `closeOnScrim` checks a native dialog's bounds (`web/ui/focus-return.ts:6–24`). These functions do not handle Escape or trap focus. `LimitsDialog`, `TripDialog` and `PortDialog` already use them (`web/app/LimitsPanel.tsx:174–190`, `web/app/Trip.tsx:76–95`, `web/landing/PortInput.tsx:123–140`).

| Difference | Nearest existing pattern (not a change proposal) |
| --- | --- |
| Coast Sources and unmanaged Report rely only on the browser (`viewer.ts:318,381`, `report.ts:48,76` in `packages/coast/src/coast3d/`). | `PortDialog`'s `showModal`/close lifecycle is the nearest native pattern (`web/landing/PortInput.tsx:127–134`). If explicit restore were needed, capture and verify focus at the host/shadow boundary; don't make the Coast package depend on the app's account selector. |
| Account `openAccount` and boat `sheet` save the active element and call `focus()` themselves (`dist/account.js:818,849–865`, `dist/boat-profile.js:33,127–130`). | Shared `rememberOpener`/`restoreFocus` for the capture/restore idea; `keepFocusIn` in `dist/account.js:784–810` is the nearest existing custom Tab pattern, not a capability of `focus-return.ts`. `PortDialog` is the native alternative pattern, not a drop-in for the legacy scrim. |
