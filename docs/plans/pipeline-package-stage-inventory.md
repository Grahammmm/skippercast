## R2. Reachability

- **From `python -m skippercast.pipeline`:** `__init__`, `__main__`, `collect`, `parsers`, `settings`, `regulations`, and conditionally `failover`, `noaa_chlorophyll`, `noaa_hfr`, `noaa_sst`. The last four are behind region/adapter selection (`__main__.py:7–8,28–40`; `collect.py:13–16,199–225,277–354`; `settings.py:6–36`). This is not a dispatcher for sibling stages. The distinct `python -m skippercast` offers only `atlas` and `validate`, not a pipeline command (`src/skippercast/__main__.py:13–22`).
- **Other workflow paths (not D):** `beach_health`, `cdip_nearshore`, `coast_report`, `coast_snapshots`, `coastal_watch`, `forecast_coverage`, `goes_frames`, `habitat_dynamics`, `intelligence`, `live`, `ndbc_history`, `ocean`, `regulation_review`, `sst_fronts`, `verification`, `verification_archive`, `wave_ensemble`. The paths are not workflow-exclusive when R1 also lists a standalone command. In particular a module that imports a daily helper is not thereby reachable **from** the daily CLI.
- **Standalone only (plus tests), not in checked-in workflow publication:** `chl_edges_region` and its `chl_edges_feed` / `chl_edges` helpers. The static forecast skill script is also standalone but reuses two modules that the Live job already reaches (`scripts/publish_forecast_skill.py:9,21–22,82–110`).
- **Test-only chains:** `backfill_layers`, `backfill_plan`, `chl_edges_history`, `eddies`, `eddies_tile`, `fronts_history`, `fronts_history_files`, all five `habitat_history*` modules, `wcofs_eddies`, `wcofs_ssh`, `wcofs_ssh_layer`, `wcofs_zeta`, `wcofs_zeta_frames`. In particular, support in the feed reader for `history` and `wcofs-ssh` does not wire these writers into `habitat_dynamics.run` (`docs/data-feed-readme.md:32–36`; `habitat_dynamics.py:373–453`).
- **No caller at all:** none found among tracked code/tests (package initializer is implicit; package `__main__` is run by `-m`). “No production caller” for the test-only rows means no path from a checked-in production command, not that the module has no imports or tests.
