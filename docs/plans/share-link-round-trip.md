| Summary | What the recipient gets | Evidence |
| --- | --- | --- |
| Place, time and fishing profile | The sender's region or coast, resolved port when available, shown profile, and a date and/or an explicit hour. A date alone is not a frozen forecast. | `web/share-link.ts:58-81`, `web/hour.ts:127-137` |
| Map and filters | Explicit, eligible URL choices, not a snapshot of the effective map. The app still checks what it can show. | `web/share-link.ts:13-25,82-91`, `web/state.ts:262-302,317-345` |

## R1. State inventory

The command bar passes the address, live region/profile, port directory and saved port ID, current clock and region zone to `shareLink`. It hands the same URL to native Share, clipboard or manual copy; cancelling the sheet does not copy (`web/app/CommandBar.tsx:117-139`, `web/share-link.ts:98-112`). The URL always starts fresh at `/map`. “Silent” below means no key-specific reason is documented at the Share boundary; the overall whitelist is intentional (`web/share-link.ts:1-4,64-91`). The seven view keys require exactly one decoded value of 1–200 characters with no whitespace, ASCII controls/DEL or `#`; this is a shape check, not app validation. Characters such as commas and colons are re-encoded, not deleted (`web/share-link.ts:13-25,82-87`, `tests/test_share_link.mjs:108-121`).
