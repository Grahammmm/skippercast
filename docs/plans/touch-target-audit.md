## R1. Method and inventory; R2. What you can actually tap

**Source:** local `origin/main` at `26aa28ab1ce4e883c0850cdb7f1243c4ed48c07e`, read November 21, 2026. `git grep -n -e '--touch-min' -- web` returned 80 **matching lines**, including comments, layout math and the `44px` token at `web/tokens.css:219`; not 80 guaranteed controls. The scope is the public map workspace, its Landing/region entry, and the Coast package CSS it uses. Standalone informational pages and separate Advisor/admin pages are not the boating workspace. No browser run or live map data.

A scratch Python script (`python3 ../audit.py web` and `python3 ../audit.py packages` from the clone) enumerated tracked `web/` and `packages/coast/` stylesheets. It split qualified rules by braces, preserving selector lines through comments/strings and printing enclosing media/supports conditions. It selected `button`, `a`, `input`, `select`, `summary`, `textarea`, `label`, role selectors (including button, tab and switch), classes collected from control markup, and control-like names (chip, range, tab, toggle, link, close, action, handle, etc.) and pointer/grab rules. It extracted physical/logical height and width, min/max, padding, font, border and display, plus potential hit-area declarations. It substituted `--touch-min`, spacing, type and leading tokens from `:root`; `--space-2/3/4/5` are 8/12/16/24 px (`web/tokens.css:188–191`). Examples from the read-only run: `21 .app-brand … min-height:24px`; `112 .app-brief-footer a … min-height:24px`; `270 .app-rail-option input … width:16px; height:16px`; `2761 .history-controls select, .range-switch button [@media (max-width: 760px)] min-height:44px`; `2919 .history-measurement-note > summary … min-height:24px`.

The script is a candidate finder, not a browser cascade engine. I checked markup, wrapper semantics, fixed sizes, breakpoints, shadow styles and shared classes before classifying the matches. The table lists selector **families** so links generated from multiple records don't inflate the inventory. Treat the named source rules as reproducible evidence: `git show 26aa28ab1ce4e883c0850cdb7f1243c4ed48c07e:<path>` or, for example, `git grep -n -E 'species-pin|history-measurement-note|app-brief-footer|app-brand' -- web packages/coast`. The existing token and contrast checkers check different contracts (`scripts/check_tokens.mjs:307–330`; `scripts/check_contrast.mjs:755–815`).

**Reading the tables:** sizes are CSS px, width × height if both are known. A fixed box is stronger evidence than a 24 px **floor** (which can grow). “No floor” means no applicable 44 px size on that axis, not a measured failure. Wrapped text, line metrics, viewport, user settings and native control defaults can change the result. A group/row containing a control does not count as a bigger hit box unless that group/row activates it. “None” means no larger area found in the cited CSS/markup. Category is the control's job, not a priority rating. Rows that mention Helm mode refer to `web/app/helm.css:2–3,11–13`; its outer-document selectors don't set the sizes of shadow-tree controls (`web/app/CoastMarkup.tsx:143–149`; `packages/coast/src/embed.ts:42–49`).
