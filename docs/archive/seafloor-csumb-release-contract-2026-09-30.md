# Original-producer release contract — September 30, 2026

CSUMB's current [SFML policy](https://csumb.edu/undersea/sfml-data-library/)
permits public use and display, requests producer acknowledgment, forbids
navigation use and requires express permission for for-profit enterprise.
NOAA distributes the reviewed originals; hosting does not convert their terms
into the federal public-domain policy. The legacy CSUMB download portal is
reported offline, but cached NOAA originals remain the reviewed source.

## Reusable qualification and publication

A source can use `csumb-public-use-noncommercial` only after an explicit dated
original-producer review bound to its original SHA256. `rights_review` must
identify CSUMB SFML, the exact official policy URL, noncommercial use, the
producer acknowledgment, no navigation use and required but unobtained
for-profit permission. Native grid receipts and existing source qualification
checks remain required. Missing/conflicting rights do not qualify.

Publication retains every contributing source, including interpreted substrate,
in `source_rights` on MVT features and canonical GeoJSON exports. Distinct terms
remain distinct; mixed sources never become wholly public-domain. Tile metadata
and the regional manifest retain the acknowledgment. A configured
`SKIPPERCAST_SOURCE_USE=for-profit` deployment rejects the CSUMB profile; the
existing personal-use app defaults to `noncommercial`. This is a specific
producer profile, not a general exception for third-party datasets.

## Release sequencing

This engine adds no usable source rows or live locations. Consumer display of
these credits and notices must be implemented before promoting CSUMB rows.
Next, qualify sources, carry verified private physics into public processing
without recomputing unchanged terrain, and apply the current whole-polygon
spatial screen. Do not publish private held geometry or restore cached public
clearance merely because a producer contract passes.

Private originals, source receipts and measured candidate geometry are not
committed. Tests cover native receipt qualification without invented public-domain
rights, conflicts and fabricated permissions, missing contributors, and producer
credits/terms surviving tiles and compressed canonical export metadata.
