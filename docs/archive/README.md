# Archived research logs

Dated audit, rollout, source-request and review records, kept as the evidence trail behind coverage and product decisions.

**Nothing here is a product claim.** Each file describes what was known, tested or decided on its date. Current product behaviour is described by the living documents in the [documentation index](../README.md); where one of them relies on a conclusion recorded here, it states the conclusion itself and links the log as evidence.

Files keep their original names so old links are easy to follow. Do not update them to describe current behaviour; write or update a living document instead.
