# Point Lobos original-source registry

The source worker reproduced `Unreviewed original-source URL` and a producer-rights rejection for the original Point Lobos archive. NOAA places this CSUMB survey under **MacGinitie**, whereas the importer previously reviewed only Harold Heath and Ventresca CSUMB namespaces. [NOAA’s cruise report](https://www.ngdc.noaa.gov/ships/macginitie/PointLobos_mb.html) identifies CSUMB SFML and links the original additional-products archive.

This change permits only the exact `https://data.ngdc.noaa.gov/platforms/ocean/ships/macginitie/PointLobos/multibeam/data/version2/products/PointLobos_additional_products.tar.gz` URL in the existing fetch, ArcInfo container and producer-rights registries. Independent review caught plain and encoded dot-segment traversal in the initial directory-prefix proposal; the final implementation uses exact URL equality at both entry points, with regression tests for traversal, alternate filenames, suffixes and query changes. Other MacGinitie surveys and lookalike paths remain unreviewed. Native decoding, limits, extraction defenses, hash checks, source qualification, noncommercial terms and final spatial screening remain required.

A bounded local smoke test imported the exact 267,635,311-byte archive (SHA256 `6ecad4d5f58cb459fa2b45abd46c386e095dcbc4817d736b703305b7bf220384`) and its original `PointLobos/PtLobos_2mbathy_hill_slope.zip/ArcViewGrids/pl_2mbathy`. The result retains 2 m spacing, 3,216,643 valid pixels and 2,180,800 nominal 0–91.44 m pixels in its requested window. The normalized COG hash is `558878a051d62be6b3d2b9cea7f00611fe1a45d25f94f538f75a865e256717bf`. Unknown vertical datum remains unknown because native and companion metadata conflict. These pixel counts prove the importer works; they are not deduplicated new coverage, fish presence or released fishing spots. No source is promoted by this code change.

Validation: 32 offline adapter/rights tests and 58 subtests passed, including allowed native import, wrong format/bytes/hash rejection, unrelated and lookalike URL rejection, original producer review, and continued rejection of for-profit use without permission. Original data and private receipts remain outside Git.
