## Completed deliverable

Large habitat windows now preserve native spacing using 1024-pixel owned tiles,
derivative halos, disk-backed arrays, exact reach-wide percentile samples,
bounded standard-deviation passes, and eight-connected component joins across
horizontal, vertical and diagonal tile edges. Area filtering happens after
joins. Feature grading and provenance use the shared small-grid method.
No reach IDs, ownership, depth rules or legal policy changed. Physical caches
include the new module hash; a repeated unchanged run verifies and reuses output.
Scratch closes on exceptions; insufficient disk fails explicitly. Resident
memory is not a fixed cap: mapped pages and complex polygons still need RAM.

Offline acceptance covers tiled/untiled geometry, stable IDs, metrics and
thresholds; soft-bottom, no-data and depth edges; diagonal components individually
below minimum size; native derivative halos; interrupted scratch cleanup; and a
21-million-pixel native fixture that completes without false reef candidates.
Equivalent polygon rings may begin at a different vertex; topology and properties
are compared, rather than requiring arbitrary ring ordering.
