# Captain feature status

This page says which captain features exist in the repository, which are only designed, and the smallest next step for each. It is a status record, not a release note. It is **not for navigation**: nothing on this page changes the caveats in the feature documents it links, and every caveat in those documents still applies.

## How to read the status column

| Status | Meaning on this page |
| --- | --- |
| LIVE | A cited deploy record proves that the served site runs a head containing the feature. **No row on this page is LIVE.** A merge to `main` does not prove what is served. A green `deploy-cloudflare.yml` run does not prove it either, because the workflow can deploy an older eligible commit or deploy nothing and still report success. |
| PREVIEW | The code and documents are merged at the pinned commit, and a merge or commit record is cited. Whether captains can see the feature on the served site, and whether its data is current, is not proven here. |
| DESIGNED | Documents, code or a dated snapshot exist, but no receipt at the pinned commit shows a qualified, cited data product. |
| UNVERIFIED | The claim cannot be checked from the repository at the pinned commit. |

A claim that a feature produced qualified, cited data counts as UNVERIFIED unless the row cites a dated receipt present at the pinned commit. Dates and run links quoted *inside* a feature document are that document's own claims. This page does not re-verify them.

## Boundaries of this page

- This is documentation only. It changes no code, data, workflow, deploy setting or feature flag, and it lifts no hold. Publication stays held except for the repository's normal build on merge.
- It includes no private charter schedule, vessel, registry or position data. Vessel names and per-boat facts stay in the linked documents and their governed stores.
- It removes no caveat from any feature document. Contours are not chart depths and not for navigation. Charter outlines are not reported positions. Bite confidence is not a catch probability. Exported files carry no route.
- Sources: Fable audit `20-SKIPPERCAST-BUILD-PLAN.md` §4 and work item S-044 in `21-SKIPPERCAST-WORK-ITEMS.json`, both read at their pinned sha256. Every repository path and commit above was read at c3fe61e5c14543013511ffa5c1744655641ef657.
- If a later main changes `docs/charter-grounds.md` or `docs/bite-evidence.md`, check this page again against the new versions before relying on it.
