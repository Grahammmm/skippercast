# Importing the atlas into iNavX

Use the public atlas's [complete.gpx](../atlas/avila-point-estero-2026-09-20/exports/complete.gpx) for one initial import. It includes waypoint notes, routes for optional drift alignments, and tracks for partial reef outlines.

1. Export or back up your existing iNavX waypoints, routes, and tracks. Keep personal notes.
2. Download the actual GPX file. On an iPad, save it to Files; if transferred by AirDrop, choose a Files location you can find again.
3. Open the file in Files, use **Share**, and choose **iNavX**. Depending on the installed version, iNavX may also offer an import action in its waypoint/route screens.
4. Enable the display of waypoints, routes, and tracks on the chart. Look for names beginning `SC26-`, `SC-AREA-`, and `SC-DRIFT-`.
5. Tap a target and open its description to read terrain, source depth, priority, evidence limits, and linked features.

The [iNavX user guide](https://inavx.com/wp-content/uploads/sites/3/2019/05/iNavX-User-Guide.pdf), [routes documentation](https://inavx.com/routes), and [track documentation](https://inavx.com/tracking) describe the app's GPX/display concepts. Menu labels and mixed-file behavior can vary by version; this public edition has not been verified on a device.

If the points appear but the outlines or lines do not, check their display settings first. Only then import the missing component file. Importing the complete file and every component produces duplicates. A route can also expose its two endpoints as additional symbols; those are not additional ranked fishing targets.

This edition contains a subset of the older private `MB26`/`V2` research. Its distinct `SC` names reduce confusion but do not eliminate overlapping positions. Avoid importing both editions unless you intend to see both. Do not use “remove all waypoints” to clean up one dataset.

Use the GPX features for fishing research. **Never activate a drift alignment as a safe passage or approach route.** The export contains no validated navigation connection from the harbor to a fishing point.
