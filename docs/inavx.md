# Import a day plan into iNavX

Use the app’s **Export** tab to choose your region and spots. Start with a few waypoints, then optionally include linked reef outlines, fixed structure alignments and protected-area references. The app checks current protected-area coverage again at export time. Outlines and alignment lines in this workflow are **tracks**, never navigation routes.

1. Back up your existing iNavX waypoints and tracks.
2. Choose **Share / Save file**, then iNavX. If the browser cannot share directly, it downloads the GPX instead.
3. Open the downloaded GPX in **Files → Downloads**, choose **Share → iNavX**, and follow the import prompt. An AirDrop transfer may use a different Files location.
4. Display imported waypoints and tracks. Check a stable `SC26-` spot ID, its latitude/longitude and its outline against SkipperCast. Track display may differ by app version.
5. Download the separate offline notes HTML if you want readable source, depth and terrain notes on your iPad. It is not a chartplotter import file and does not update offline.

[Official waypoint help](https://inavx.com/h/inavx/waypoints.htm) documents GPX import. [Official track help](https://inavx.com/h/inavx/track.htm) describes tracks and their display. This release has not been imported on a physical iNavX device; browser sharing does not confirm a successful import.

Reimporting can create duplicates. Use the stable spot IDs to compare sets and remove only an obsolete set after backing up. Never remove all personal waypoints just to replace a SkipperCast plan.

The archived [complete.gpx](../atlas/avila-point-estero-2026-09-20/exports/complete.gpx) remains a dated research artifact; it includes route-form drift alignments and is not the app’s current, guarded export workflow. Do not activate those archived routes for navigation. See [chartplotter export](chartplotter-export.md) for device-specific storage, limits and the reusable regional export process.
