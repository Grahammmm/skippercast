# Source preparation and real trial acceptance

## Pin the actual integration

Use an isolated checkout of current main and the smallest reviewed dependency
closure. Preserve unrelated work, fleet registries, source originals and held
jobs. Register new schemas in the actual validator and package their resources;
source-tree success does not prove an installed validator or launcher can find
them. Pin the final source commit, wheel, portable bundle, catalog, policies,
grants and registry identities after the final source change. Validate their
actual emitted file names, byte counts, transitive dependencies and import paths.
A prototype package or a historical successful wheel is not current release
acceptance. Keep research adapters in research; product code cannot import them.

Record source-checked, packaged, installed and runtime-accepted states separately.
Use an existing supported standalone route when available; an optional agent
framework is not a prerequisite. The route must still prove owned process
containment, resource limits, original-source isolation where required, durable
receipts and descendant cleanup. A process-group deadline is not proof of
cgroup containment, reboot recovery or power-loss durability.

## Preserve accounting and geography

Inventory owned preparation output and scratch without opening originals.
Choose finite file, byte, test and time allowances sized to the emitted workload;
record any authorized increase and inventory evidence. Historical remaining
source allowance is not fresh preparation headroom. Carry all spent attempts,
charges, reservations and stopped mission identities; no rename, new stage or
cleanup refunds them. Stop before an admission would exceed its allowance.

Derive a geographic segment from accepted CRS and whole artifact bounds against
the existing registry. Keep source/window lineage separate from geography.
Several windows inside one segment are several artifacts, not several distinct
geographic maps or whole-cell measurement coverage. Measure deduplicated native
support; preserve holes, uncertainty, datum limitations and unassessed habitat.

## Prepare one bounded real trial

Inventory retained discovery evidence first. Select actual candidate inputs and
a region with a useful measurable delta, rather than repeating a small fixture
to fill the clock. A requested 60-minute stage is a ceiling including cleanup;
stop when the accepted output is complete or a specific dependency blocks it.
Use a new authorized mission linked to upstream evidence, while retaining legacy
terminal jobs and their nonrefundable counters. Pin an immutable manifest with
stage dependencies, input identities, candidate windows, output graph, ceilings,
acceptance checks and reproducible entry point. A placeholder input or unresolved
runtime grant means the trial remains unready; do not label it executable.

Discovery must produce a reviewed inventory and explicit reader/rights/quality
holds. Native qualification must test real masks, units, vertical semantics and
valid support before mapping. Each requested distinct map needs its own accepted
geographic scope and support union. Render only accepted mapping inputs and
inspect all selected cores, holes and depth range. Static previews retain actual
browser interaction as unknown. Browser acceptance requires the requested
loader, camera/control behavior and regional feature checks on the actual view.
Private preview success does not authorize deployment or public acceptance.

Record queue claims and completion, duplicate/idempotent resume, interrupted
worker recovery, failure retention and cleanup with the same mission identity.
Do not reset attempts or rearm a terminal mission. Independently review both
scientific artifacts and operational receipts before acceptance. Expiry alone is
not a new blanket hold; apply normal current evidence validity and exact scope,
and preserve genuine rights, scientific and private-data restrictions.

Report each stage as prepared, attempted, accepted or blocked with exact evidence.
Synthetic test counts, artifacts and elapsed runtime cannot substitute for an
actual skill trial. Account raw input, cached input and output tokens separately;
keep usage or dollar cost unknown when measurements or dated rates are absent.
End with one consolidated list of the uncovered trial, install and publication
actions, with direct launcher/manifest references instead of command-copying.
