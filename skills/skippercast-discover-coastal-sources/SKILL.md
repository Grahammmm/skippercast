# Discover coastal sources within a fixed allowance

## Shared implementation and private trials

Declare the requested mode: source evidence, private data-only terrain,
paired terrain/imagery, habitat interpretation, or public release. Use the
[mode-specific gates and trial lessons](references/coastal-pipeline.md#operating-modes-and-bounded-trial-lessons).
Habitat, imagery and publication are optional downstream assignments when the
owner requests them; they do not block authorized private terrain evidence.
Keep a nominal MLLW claim explicit when its realization remains unknown.

Follow [the shared coastal pipeline contract](references/coastal-pipeline.md) for package commands and current evidence gates. The coordinator discovery stage currently examines an explicit frozen local candidate catalog; it does not claim external discovery or acquisition occurred. Existing bounded public-source discovery remains a separate host operation within its approved allowlist and original allowance. Fresh scalar-packet v1 handoffs cannot establish current mapping readiness.

Use for a named coastal region whose source readiness is unresolved. Read the
repository instructions, requested region and existing source manifests first.
Keep region names, host paths, run dates and model usage in the private run
receipt. This skill produces source evidence and acquisition recipes; it does
not map terrain, accept habitat, render, publish or schedule work. For an assigned
native sample quality task, use [bounded quality assessment](references/bounded-quality.md)
after source-linked acquisition. Metadata-only review cannot establish sample
quality; one bounded native window cannot certify a source or survey.
For a specifically assigned format-aware acquisition iteration, read
[format preflight and cached samples](references/format-readers.md). The optional
60-minute profile must be selected explicitly; the default remains 30 minutes.
For an explicitly assigned bounded resumable GSF scan, follow [sequential replay](references/gsf-resume.md); its separate receipt never changes source or mapping acceptance.

Prefer original publishers' finite catalog metadata, footprints and documented
APIs. Identify local agencies appropriate to the region rather than treating a
US catalog as universal coverage. Use existing provider adapters and stable
publisher IDs. A mirror is an alternate for the same source lineage, not a new
independent measurement. Record inaccessible, rejected and unknown sources.

Read [the bounded procedure](references/bounded-discovery.md) for commands and
the source-manifest fields. Initialize once for an owner-authorized trial;
never start a trial just because the skill describes one. Its default maximum
is 30 wall minutes: 25 discovery minutes plus five minutes to stop, checkpoint
and report, with 250,000,000 total response-body bytes. Use the same checkpoint
across resume, model changes, failures and repairs. The script enforces finite
catalog, query, candidate, request, retry and stream limits. Never expand hosts
or catalogs during a run or bypass authentication, rate limits or access stops.

First reuse unexpired compatible source evidence; the source, method, policy,
region and original plan identities must still match. Preserve the original
time checked and expiry. A missing local cache does not prove missing public
data. After a cache miss, take one real, finite official external discovery
branch within the authorized allowance. Stop early if that branch is blocked;
do not perform repeated open-ended web search or use a larger model to overcome
missing data/access. Follow literal returned links only within the original
official host allowlist and remaining query/byte bounds.

Keep catalog bounding boxes, catalog footprints and actual valid data support
distinct. Require explicit geometry CRS; never label projected coordinates as
longitude/latitude. Preserve native CRS, resolution, vertical datum/sign/units,
rights, size/hash availability, cache state and exact acquisition URLs. Unknown
fields remain null or explicitly unknown. Metadata cannot establish measured
0–300 ft support, native quality, public permission or a useful habitat delta.

Record terrain, habitat and rendering readiness independently. An actionable
terrain source can remain a private qualification candidate when imagery,
license or vertical datum needs review; this does not accept that terrain.
Missing imagery cannot block private terrain source discovery. Downstream
mapping still qualifies native support and preserves quality holds. The paired-imagery website lane
consumes its reviewed render v2.1 handoff and requires imagery rights,
correspondence and website-display acceptance. An explicitly requested private
data-only terrain preview uses its separately reviewed terrain-only contract;
it does not require imagery or establish habitat or website acceptance. A discovery
PARTIAL manifest never selects render slices or passes as that handoff. Preserve
valid metadata leads with unknown native CRS in `lead_source_ids`; these are
distinct from `usable_source_ids` and `sample_observed_source_ids`. Missing
native metadata is a targeted acquisition/inspection question, not lost evidence.

Use deterministic extraction, filtering, deduplication and budgeting. Send only
compact metadata and decisive unknowns to a model, never one model call per
catalog page. Recommend at most `gpt-6.1-sol` medium for normal discovery only
after it passes comparable task evidence; a smaller available model can be
calibrated on the same fixtures. The build and offline tests do not prove any
model's live discovery quality or cheapest setting. Honor an owner's requested
model for a particular build/review; reserve stronger models for supported
exceptions. Record actual model/effort and raw input/cached/output usage when
available; otherwise keep them unknown. Do not alter gateway or model settings.

Finalize the strongest usable partial manifest, request log, exact start/cutoff/
deadline/stop, bytes observed and conservatively charged, unknown usage, failed
and rejected alternatives, remaining owned jobs and one next action. Discovery
completion is distinct from downstream acceptance. Reuse this evidence in
`skippercast-map-coast`; use `skippercast-discover-data` for broader regional
needs. New mapping/rendering runs and publication retain their own scope.
